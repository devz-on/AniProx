AniProx HLS Lab

Client-first M3U8 player

Direct mode keeps video traffic in the browser. Header Bridge mode is the practical escape hatch for streams that require forbidden browser headers such as Referer, Origin, or User-Agent: the client controls the request, while this server only relays the playlist/segments when the browser cannot send those headers itself.

Browser JavaScript still cannot spoof forbidden headers. The “break the wall” implementation here is mode-aware: try direct first, detect browser/header limits, then use Header Bridge only when a stream host requires headers that the browser is not allowed to set. 

        


        

          
What each mode does

          

            

              Direct browser loads the M3U8
              URL exactly from the stream host. It is the pure client-side path,
              but it can only use headers allowed by Fetch/XHR and by CORS.
            

            

              Header Bridge creates a
              same-origin playlist URL for the browser. The server fetches the
              upstream playlist with your JSON headers, rewrites child
              playlists, keys, and media segments back through AniProx, then
              streams bytes to the video element.
            

            

              The provided Mewstream sample returns 403 without the
              Megaplay referer in command-line testing, so Header Bridge is the
              expected working mode for that URL.
