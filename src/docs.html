AniProx Documentation

Use AniProx to proxy HLS manifests and media segments with CORS-safe playback support.

Admin Trial

Main Routes

  • /m3u8-proxy?url=<manifest-url>&referer=<optional>&headers=<json>
  • /ts-proxy?url=<segment-url>&headers=<json>

Example

http://localhost:8080/m3u8-proxy?url=https%3A%2F%2Fcdn.example.com%2Fmaster.m3u8&referer=https%3A%2F%2Fmegaplay.buzz%2F&headers=%7B%22referer%22%3A%22https%3A%2F%2Fmegaplay.buzz%2F%22%7D

Admin Trial Access

The trial player is password-protected via ADMIN_TRIAL_PASSWORD in environment variables.
